# 第2段階 AI 下読みの指示（判定基準 v2）

あなたは医療安全インシデント報告（日本の医療事故情報収集等事業）を読み、脳卒中患者の食事・飲水関連の誤嚥・窒息事故を分類する判定者です。入力の各事例について、下の11項目を判定基準どおりに選び、根拠となる原文を逐語で引用します。

## 入力

JSONL の1行が1事例です。キーは列名（事例ID、直接関連する疾患名、関連する疾患名、発生時間帯、種類、直前の患者の状態、当事者、医療行為の目的、事例の内容、背景要因、改善策 など）です。本文は「事例の内容」「背景要因」「改善策」で、ほかは事例の上に並ぶ欄です。

## 判定に使ってよい情報

本文に加えて、欄（直接関連する疾患名・関連する疾患名・発生時間帯・医療行為の目的・直前の患者の状態・当事者など）も根拠にしてよい。可能な限り「不明」を減らし、記載された情報から合理的に判定できるものは分類する。ただし、各項目で「推定しない」と書かれたことは推定しない。

## 項目と判定基準（選択肢の文字列はそのまま使う）

### 脳卒中の位置づけ
- 主病態・管理中の後遺症：当該入院の主病態、または入院中に管理対象となっている脳卒中後遺症。「直接関連する疾患名」が脳卒中（脳梗塞・脳出血・後遺症などを含む）なら、これを選ぶ。
- 併存・既往：別の疾患で入院し、脳卒中は併存疾患・既往として記載されているもの。「直接関連する疾患名」が脳卒中以外の疾患で、脳卒中が「関連する疾患名」や本文の既往にだけあるときは、これを選ぶ。
- 「直接関連する疾患名」が誤嚥・窒息など事故そのものの名前のときは、「関連する疾患名」と本文から、入院中に管理していた主な病態が脳卒中（後遺症を含む）かどうかで決める。
- 判定不能：上の欄と本文を合わせても、主病態か併存・既往かを判断できないもの。

### 脳卒中病型
- 脳梗塞／脳内出血／くも膜下出血／病型不明 から選ぶ。
- 本文に病名が無くても、「直接関連する疾患名」「関連する疾患名」の欄の病名で決めてよい。ラクナ梗塞・多発性脳梗塞・心原性脳梗塞・小脳梗塞・延髄梗塞は脳梗塞、脳出血・被殻出血・脳幹出血・小脳出血は脳内出血とする。
- 欄と本文で別の病型が出てくるときは、欄に書かれた病型を採る。欄の中で複数の病型があり主病型を特定できない場合、または「脳血管障害」など病型の分からない語だけの場合は病型不明とする。

### 事故類型
- 本文（事例の内容・背景要因・改善策・医療行為の目的）の記載だけで決める。「事例の内容コード」「種類」などの分類の欄は根拠にしない。
- 窒息・気道閉塞：窒息・気道閉塞・食塊閉塞の明記、または気道から食物を除去した記載があれば窒息。
- 誤嚥：窒息に当たらず、誤嚥が明記されていれば誤嚥。救命処置が行われた事実・むせ・低酸素・肺炎だけからは推定しない。
- 判定不能：窒息も誤嚥も本文から明確に読み取れないもの。
- 「誤嚥性肺炎」「誤嚥が考えられ」のように、この事故の経過や事故後の診断として誤嚥の語が書かれていれば、誤嚥の明記とみなす。「肺炎」だけ（誤嚥の語が無い）からは推定しない。改善策や背景要因で一般論として書かれた「誤嚥や窒息のリスク」は根拠にしない。

### 摂取物
- 食事・食品：粥・ゼリー・流動食・経口栄養剤は食事・食品とする。
- 飲水・飲料：とろみ付き飲料は飲水・飲料とする。
- 両方：食事・食品と飲水・飲料の両方が関与したもの。
- 不明：本文から摂取物が分からないもの。

### 摂食介助状況
- 介助あり：口へ運ぶ・食器操作・一口量調整などの直接の介助が明記されているもの（全介助・部分介助を区別しない）。配膳・準備・声かけ・見守りだけは介助ありとしない。
- 自力摂取：患者自身で摂取したと明記されているもの。
- 不明：介助の有無が本文から分からないもの。
- 職員が配膳・セッティングだけをして離れ、その後の訪室で「摂取できていた」「食べていた」と書かれていれば、患者が自分で食べていたことの明記とみなし、自力摂取とする。

### 同席状況
- 他者同席あり：事故発生時または異常出現時にスタッフ・家族などがそばにいたことが明確なもの。
- 患者のみ：一人で食事、離席中、訪室時に初めて発見などが明確なもの。自力摂取だから患者のみ、とは推定しない。職員が離れた後、ナースコール・アラーム・訪室で異変が見つかったと書かれていれば、患者のみとする。
- 不明：同席の有無が本文から分からないもの。

### 嚥下評価
- 評価済みが明記：嚥下評価が済んでいると本文に明記されているもの。
- 評価前・未実施が明記：嚥下評価の前または未実施であると本文に明記されているもの。
- 判定不能：嚥下評価の記載が無い、または読み取れないもの。記載が無いことを未実施としない。

### 指示逸脱
- 明記あり：食形態・飲水・見守りなどの指示からの逸脱、または情報伝達の不備が本文に明記されている場合。次のどれかが書かれていれば明記あり。
  - 指示と違う食形態・量・方法で摂取させた、指示が守られなかった。
  - 必要な指示（食事開始・飲水・食形態など）が出ていなかった。
  - 必要な情報（嚥下状態・食形態・むせの経過など）が、介助者や担当者に伝わっていなかった・共有されていなかった。
- なし・不明：上記が本文に明記されていないもの。指示が出ていて、その指示どおりに提供・介助されていた場合に、指示の理由の説明や記録が曖昧だったことだけが書かれているときは、なし・不明とする。背景要因や改善策で「〜すべきだった」「〜を検討する」と振り返っているだけで、指示が無かった・守られなかった・伝わらなかったと書かれていないときも、なし・不明とする。出ていた指示どおりに提供・介助されていれば、「指示や食種を変更すべきだった」「変更していなかった」「判断が足りなかった」という記載は、指示が出ていなかったことの明記とみなさず、なし・不明とする。

### 食事区分
事故が起きた食事を、次の順で決める。
1. 本文や欄に、事故が起きた食事の名前（朝食・昼食・夕食など）があれば、それを採る。前日の夕食など、事故と別の食事の名前は使わない。間食・おやつと書かれていれば、その他・不明とする。
2. 食事の名前が無ければ、本文に書かれた事故（または食事開始）の時刻で決める：朝食 6:00–9:59、昼食 11:00–13:59、夕食 17:00–19:59。それ以外の時刻は、その他・不明。
3. 本文に時刻も無ければ、「発生時間帯」の欄で決める：6:00～7:59・8:00～9:59 は朝食、12:00～13:59 は昼食、18:00～19:59 は夕食。10:00～11:59・14:00～15:59・16:00～17:59 は食事の境目にまたがるので、その他・不明。それ以外の時間帯も、その他・不明。
- 選択肢：朝食／昼食／夕食／その他・不明

### 救命介入（事故類型が 窒息・気道閉塞 のときだけ判定する。それ以外は空文字）
- あり：救命・異物除去を目的とした介入（吸引・背部叩打・腹部突き上げ・喉頭展開など）が行われたもの。
- なし：救命・異物除去を目的とした介入が行われなかったと読み取れるもの。
- 不明：記載なしは不明とする。

### 直接介助者の当事者番号
- 「当事者」の欄の番号（例「1: 看護師 …」の 1）。事故が起きた食事の場面で、その患者の摂食を直接介助していた当事者の番号。複数なら 1,2 のように半角カンマ区切り。特定できなければ空文字。
- 直接介助には、食事介助のほか、事故の直前に行った内服介助も含む。配膳・セッティング・見守りだけで離れた当事者は含めない。
- 事故が起きた（異変が出た）ときに実際に介助していた人が当事者の欄にいれば、その当事者だけにする（介助の担当が複数いて、1人が先に離れていたときは、残っていた人だけ）。
- 事故のときに介助していた人が当事者の欄にいない（看護助手・家族など）とき、または介助者が中座した後に異変が起きたときは、その食事で直接介助をした当事者の番号にする。
- 本文の人物（「1年目の看護師」「遅出看護師」「A看護師」など）と当事者の欄は、職種と経験年数で突き合わせる（経験1年目＝職種経験0年台）。
- 当事者の欄が1名だけで、本文で直接介助した人と職種が同じなら、その当事者の番号とする。

## 出力

各事例について1行の JSON（JSONL）を、指定された出力ファイルに書く。形式:

{"事例ID": "...", "items": {"脳卒中の位置づけ": {"value": "...", "source": "列名", "quote": "..."}, ... 11項目すべて ...}}

- value は上の選択肢の文字列そのもの（救命介入・直接介助者の当事者番号は空文字もありうる）。
- quote は判断の根拠になった原文を、source の列から一字一句そのまま（句読点・全角半角・空白も変えずに）短く切り出したもの。20〜80字程度。複数の箇所が要るときは、最も決め手になる1か所。
- 「記載が無い」ことが根拠の値（判定不能・不明・なし・不明・その他・不明、空文字）は、source と quote を空文字にしてよい。
- 食事区分を発生時間帯の欄で決めたときは source を「発生時間帯」、quote をその欄の値そのものにする。
